# Novelify sample content

Novelify automatically copies this content to `Assets/NovelifyGenerated/Samples`
when the package is first imported. Edit those project copies freely; editor
reloads and package updates preserve them.

Open `Scenes/TestScene.unity` and press Play to run `NovelGraphs/Example.novelgraph`.
Click or press Space to advance. Use the generated Backlog, Auto, Skip and
Settings controls. Double-click the graph to edit its story.

`Characters` contains Daisy, Hoki and the emotion-layered Template character.
Their portrait layers and talking clips are included, along with the sample's
background, music, sounds, presentation styles, prefabs and localization table.

The sample scene does not require URP. Installation configures its EventSystem
for the Input System when available; otherwise it uses legacy input.
